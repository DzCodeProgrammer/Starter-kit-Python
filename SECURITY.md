# Security Policy

## Supported versions

Security fixes are applied to the latest commit on `main`. This starter kit is currently
pre-1.0, so consumers should track the latest release or commit when possible.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's
[private vulnerability reporting](https://github.com/DzCodeProgrammer/Starter-kit-Python/security/advisories/new)
and include:

- affected version or commit
- reproduction steps or proof of concept
- potential impact
- any suggested remediation

Avoid including real secrets, personal data, or production credentials in the report.
