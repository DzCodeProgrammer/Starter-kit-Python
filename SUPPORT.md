# Support

## Questions and usage help

Search the documentation and existing issues first. If the answer is not available, open a
GitHub discussion when enabled, or a focused issue containing the goal, commands attempted,
environment details, and a minimal reproduction.

## Bugs

Use the bug report form and include only sanitized logs. Reproducible examples receive the
fastest response; incomplete reports may be returned for more information.

## Security

Do not use public support channels for vulnerabilities. Follow [SECURITY.md](SECURITY.md) to
send a private report.

This project is maintained on a best-effort basis and does not include a response-time or
service-level guarantee.
